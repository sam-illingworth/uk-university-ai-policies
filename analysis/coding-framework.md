# Qualitative Coding Framework

## Sampling Strategy

Stratified sample of ~20 policies:
- 6 Russell Group
- 6 Post-1992
- 4 Pre-1992 non-Russell Group
- 4 Specialist/other

Selection criteria: purposive sampling informed by computational framing ratios. Include policies from across the framing spectrum (high detection, balanced, high education) within each type. Prioritise geographic spread across UK nations.

## Coding Categories

### A. Student-Centredness (from Sam's four pillars)

| Code | Description | Example |
|------|-------------|---------|
| A1 | Students as agents | 'Students should decide when AI is appropriate for their learning' |
| A2 | Students as potential cheaters | 'Students must not use AI to generate work they submit' |
| A3 | Students as passive recipients | 'Students should be aware that AI tools exist' |
| A4 | Students consulted/involved | Reference to student voice in policy development |

### B. Trust

| Code | Description | Example |
|------|-------------|---------|
| B1 | Good faith assumed | 'We trust students to use AI responsibly' |
| B2 | Bad faith assumed | 'All submissions will be checked for AI-generated content' |
| B3 | Trust conditional | 'With appropriate acknowledgement, AI use is acceptable' |
| B4 | Trust not addressed | No explicit framing of trust |

### C. Relevance

| Code | Description | Example |
|------|-------------|---------|
| C1 | Connected to teaching practice | Specific guidance linked to assessment types or disciplines |
| C2 | Abstract/generic | Generic statements about AI without disciplinary context |
| C3 | Discipline-specific variation | Acknowledges different approaches for different subjects |
| C4 | Real-world relevance | Links AI skills to employability or professional practice |

### D. Agency

| Code | Description | Example |
|------|-------------|---------|
| D1 | Student agency supported | Students given choices about AI use |
| D2 | Staff agency supported | Staff given flexibility in how they approach AI |
| D3 | Prescriptive/rigid | Fixed rules with no room for interpretation |
| D4 | Delegated to module level | Policy defers to individual module decisions |

### E. Deficit Model Indicators

| Code | Description | Example |
|------|-------------|---------|
| E1 | One-way communication | Policy tells; does not invite dialogue |
| E2 | Dialogic approach | Policy invites discussion, feedback, or co-creation |
| E3 | Tool proficiency focus | 'How to use AI responsibly' |
| E4 | Critical literacy focus | 'When, why, and whether to use AI' |
| E5 | Punishment focus | Primary emphasis on penalties for misuse |
| E6 | Learning focus | Primary emphasis on developing understanding |
| E7 | Binary framing | AI use is either permitted or not |
| E8 | Nuanced framing | Spectrum of acceptable AI engagement |

### F. Structural/Institutional Framing

| Code | Description | Notes |
|------|-------------|-------|
| F1 | Located in academic misconduct | Policy sits within misconduct/integrity pages |
| F2 | Located in teaching and learning | Policy sits within T&L or pedagogy pages |
| F3 | Standalone AI guidance | Dedicated AI guidance section |
| F4 | Part of digital strategy | Policy sits within wider digital/IT strategy |
| F5 | Student-facing only | Written for students, not staff |
| F6 | Staff-facing only | Written for staff, not students |
| F7 | Dual audience | Addresses both staff and students |

## Coding Procedure

1. Read each policy in full before coding
2. Code at paragraph level (not sentence level)
3. A paragraph can receive multiple codes
4. Record illustrative quotes for each code applied
5. After initial coding, review codes for consistency
6. Calculate inter-coder reliability if a second coder is available

## Key Questions for Qualitative Analysis

1. Do policies frame AI primarily as a threat to be managed or an opportunity to be developed?
2. Is there a difference in framing between policy types (misconduct vs guidance)?
3. Do Russell Group universities frame AI differently from post-1992 universities?
4. Where policies mention 'AI literacy', do they mean tool proficiency or critical literacy?
5. Do policies acknowledge disciplinary variation or impose uniform rules?
6. Is there evidence of student or staff consultation in policy development?
7. Do policies reference sector guidance (QAA, Jisc, Russell Group principles)?
