### Sensitivity analysis

The education-dominant finding (86.6% at 0.4 threshold) is robust:
- At conservative thresholds of 0.3/0.5: 77.3% education-dominant
- Removing 'academic integrity' from the detection vocabulary: 89.7% education-dominant
- The corpus median framing ratio is 0.188, with 87% of policies falling below 0.3

## Supplement B: Qualitative Coding Framework

### Coding categories

#### A. Student-centredness

| Code | Description | Illustrative example |
|------|-------------|---------------------|
| A1 | Students positioned as agents capable of informed decisions | 'Students should decide when AI is appropriate for their learning' |
| A2 | Students positioned as potential cheaters requiring surveillance | 'Students must not use AI to generate work they submit as their own' |
| A3 | Students positioned as passive recipients of institutional rules | 'Students should be aware that AI tools exist and follow institutional guidance' |
| A4 | Students consulted or involved in policy development | Reference to student working groups, feedback mechanisms, co-creation |

#### B. Trust

| Code | Description | Illustrative example |
|------|-------------|---------------------|
| B1 | Good faith assumed as default | 'We trust students to use AI responsibly in their learning' |
| B2 | Bad faith assumed as default | 'All submissions will be checked for AI-generated content' |
| B3 | Trust conditional on transparency/compliance | 'With appropriate acknowledgement and declaration, AI use is acceptable' |
| B4 | Trust not explicitly addressed | No framing of institutional trust toward students |

#### C. Relevance

| Code | Description | Illustrative example |
|------|-------------|---------------------|
| C1 | Guidance connected to actual teaching practice | Specific guidance linked to assessment types, disciplinary examples |
| C2 | Guidance abstract or generic | Generic statements about AI without disciplinary context |
| C3 | Discipline-specific variation acknowledged | Explicit acknowledgement that appropriate AI use differs by subject |
| C4 | Real-world/employability relevance | Links AI skills to graduate outcomes or professional practice |

#### D. Agency

| Code | Description | Illustrative example |
|------|-------------|---------------------|
| D1 | Student agency supported with genuine choices | Students given meaningful flexibility in how they engage with AI |
| D2 | Staff agency supported with professional discretion | Staff given flexibility in how they approach AI in their teaching |
| D3 | Prescriptive/rigid rules with no interpretive room | Fixed binary rules: permitted or not permitted |
| D4 | Delegated to module level | Policy defers operational decisions to individual modules |

#### E. Deficit model indicators

| Code | Description | Illustrative example |
|------|-------------|---------------------|
| E1 | One-way communication (telling) | Policy instructs without inviting dialogue or feedback |
| E2 | Dialogic approach (inviting) | Policy invites discussion, includes feedback forms, credits student input |
| E3 | Tool proficiency focus | 'How to use AI responsibly and effectively' |
| E4 | Critical literacy focus | 'When, why, and whether to use AI; whose interests AI serves' |
| E5 | Punishment focus | Primary emphasis on penalties, sanctions, and consequences for misuse |
| E6 | Learning focus | Primary emphasis on developing understanding and capability |
| E7 | Binary framing | AI use categorised as permitted or prohibited, acceptable or unacceptable |
| E8 | Nuanced framing | Spectrum of AI engagement acknowledged; context-dependent guidance |

#### F. Structural/institutional framing

| Code | Description |
|------|-------------|
| F1 | Located within academic misconduct/integrity framework |
| F2 | Located within teaching and learning pages |
| F3 | Standalone AI guidance section |
| F4 | Located within digital strategy or IT pages |
| F5 | Student-facing audience only |
| F6 | Staff-facing audience only |
| F7 | Dual audience (staff and students) |

### Decision rules for performative education framing

A policy was classified as performatively educational when all three criteria were met:

1. It received education-oriented codes (A1, B1, D1) in its opening or framing sections
2. It received detection-oriented codes (A2, B2, D3, E5, E7) in its operational body
3. The operational requirements (what students must do) contradicted the stated educational aspirations

Where the contradiction was partial or ambiguous, the policy was coded as 'balanced' rather than performative.

### Overall assessment categories

Each policy received an overall assessment:
- **Dominant frame:** Education / Balanced / Detection
- **Deficit model strength:** Strong / Moderate / Weak / Absent
- **Performative framing:** Yes / No / Partial
